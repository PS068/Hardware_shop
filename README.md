## 🏗️ Project Overview

Jyotirling Hardware Premium is a static web project built with HTML and Tailwind CSS. It features a high-end hardware marketplace interface with sections for:

- Home / hero showcase
- Product categories
- Professional center
- About company
- Contact and consultation

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm

### Install dependencies

```bash
npm install
```

### Run the project locally

To generate the CSS and watch for changes:

```bash
npm run dev
```

This project is a static site, so you can also preview it directly by opening `index.html` in a browser.

### Build production CSS

```bash
npm run build:css
```

## 🌐 Preview

The landing entry point is:

- `index.html` → redirects to `pages/homepage.html`

You can also open the page directly from the `pages/` folder for specific sections.

## 🎨 Customization
